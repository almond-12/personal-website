# Personal Website Build Plan

## Stack
- React 18 + Vite
- Tailwind CSS v3
- Framer Motion (scroll animations)
- Inter font (Google Fonts)

## Sections (matching Elevatr layout)
1. Navbar (sticky, glassmorphism, dark/light toggle)
2. Hero — name, title, bio, CTA buttons
3. About — extended bio + quick stats
4. Services — 6 skill cards with icons
5. Contact — email + social links
6. Footer

## Color System
- Dark: `#0D0D0D` background, `#1A1A1A` cards
- Light: `#FAFAFA` background, `#FFFFFF` cards
- Accent: Warm gold `#C9A84C` / `#E2B96C`
- Text dark mode: `#EDEDED` primary, `#888` muted
- Text light mode: `#111` primary, `#555` muted
